Emura Support

Emura plays the Game Boy, Game Boy Color, Game Boy Advance, DS and 3DS games you own, on iPhone.

Questions, a game that doesn't run right, an idea? Write to emura.support@icloud.com. Say which game and which iPhone, and what you saw.

Adding games

Emura doesn't come with games. Add the games you own from Files, iCloud Drive or a computer: tap Import Games in the Library. Each game gets its own page, and its saves stay beside it. 3DS games must be decrypted (.3ds, .cci, .cxi).

Saves

Games save the way they always did. Emura also keeps your place when you leave a game, so Play reopens it where you stopped. Supporters can make save states, as many as they like.

Controllers and skins

Game controllers and keyboards work as soon as they're connected; Settings › Controllers shows which button does what. Skins made for Delta (.deltaskin files) can be imported for free in Settings › Skins.

Artwork

Each game gets its real box, title screen and screenshot when one exists. With your own free SteamGridDB key (Settings › Artwork), games also get backgrounds and logos. You can change any picture in a game's Edit page.

Supporting Emura

Every system plays free. Supporters get save states, faster fast forward, their iPhone's colors on the console and Screen Light. Subscriptions are managed in your iPhone's Settings › your name › Subscriptions.

Privacy

Emura collects nothing about you. Read the privacy policy.
