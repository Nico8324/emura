はじめに

ゲーム

Emura はどのデバイスで使えますか？

iOS 27 または iPadOS 27 以降の iPhone と iPad で使えます。Mac と Apple TV にはまだ対応していません。

Emura にゲームは入っていますか？

いいえ。Emura はお持ちのゲームを遊ぶアプリです。「ファイル」、iCloud Drive、またはコンピュータから追加できます。ライブラリで「ゲームを読み込む」をタップしてください。ゲームごとに専用ページがあり、セーブデータもそこにまとまります。

ゲームはどこで手に入れますか？

お持ちのカートリッジやゲームカードからです。Emura にゲームは入っておらず、ゲームを探すお手伝いもできません。

どのファイルを追加できますか？

Game Boy は .gb、Game Boy Color は .gbc、Game Boy Advance は .gba、DS は .nds、3DS は .3ds、.cci、.cxi です。zip 圧縮されたゲームは、先に展開してください。「ファイル」で zip をタップすると展開できます。

3DS ゲームが暗号化されていると表示されます。

Emura で遊べるのは復号済みの 3DS ゲームのみです。Emura 自体は鍵を持っていません。

3DS ゲームを.cia で追加できますか？

いいえ。ゲーム本体は復号済みの .3ds、.cci、.cxi ファイルで追加してください。.cia が使えるのは、ゲームの更新データと追加コンテンツだけです。

3DS ゲームの更新データや追加コンテンツを追加するには？

ゲームのページで「編集」をタップし、「更新データを追加」または「追加コンテンツを追加」をタップします。どちらも復号済みのファイルが必要です。更新データは .cia または .cxi、追加コンテンツは .cia です（購入したすべてのパックが 1 つのファイルに入っています）。

別の更新データで作成したステートセーブはロードできません。ゲーム内のセーブには影響しません。

BIOS やファームウェアは必要ですか？

いいえ。どのゲーム機でも、システムファイルは必要ありません。BIOS、ファームウェア、鍵、システムフォントのどれも不要です。

Emura にJIT は必要ですか？

いいえ。3DS を含むすべてのゲーム機が、App Store からそのまま、JIT なしで動きます。

Emura にインターネット接続は必要ですか？

ゲームはオフラインで遊べます。Emura がオンラインになるのは、ゲームのアートワークと詳細情報の取得、サブスクリプションのための App Store、そしてサポーターの場合はセーブデータを同期するための iCloud だけです。

プレイ

セーブとゲームメニュー

メニューはどこですか？

Select と Start のあいだにある Emura ボタンをタップします（スキンを使っている場合は、スキンの作者が決めた位置にあります）。ゲームが一時停止し、メニューにはステートセーブ、早送り、「ボタンを押したままにする」、スクリーンショット、「最初から」、「ゲームを終了」があります。

ゲームをやめると、進行状況は失われますか？

ゲームがセーブした内容は失われません。ゲームはこれまでどおりの方法でセーブされます。やめる前にゲーム内でセーブすれば、次回はそこから始まります。サポーターのゲームは、中断したところからそのまま再開します。

ステートセーブはどのように使いますか？

ステートセーブはサポーター向けの機能です。ゲームメニューの「ステートセーブ」でその瞬間を保存でき、「ステートセーブ一覧」には画像付きで一覧表示され、ロード、名前の変更、共有、削除ができます。ほかの人が共有したステートセーブを読み込むこともできます。

Emura のかなり古いバージョンや新しいバージョンで作成したステートセーブは、ロードできない場合があります。その場合はアプリがお知らせします。ゲーム内のセーブは常に安全です。

ほかのアプリやゲーム機のセーブデータを使えますか？

はい、無料で使えます。ゲームのページで「編集」をタップし、「セーブデータを読み込む」を選んでください。ゲームボーイ、ゲームボーイアドバンス、DS のゲームは .sav や .dsv ファイルのほか、よく使われる DS のセーブ形式に対応しています。3DS のゲームは、3DS のセーブ管理ツールで作ったセーブフォルダ、またはその中のファイルを読み込みます。置き換えたセーブデータは保管され、「前のセーブデータに戻す」で元に戻せます。「セーブデータを書き出す」で反対方向にも移せます。

ほかのエミュレーターのステートセーブは使えますか？

いいえ。ステートセーブは、作ったアプリでしか使えません。代わりに「セーブデータを読み込む」でゲーム内のセーブデータを移してください。

早送りはどのくらい速いですか？

誰でも 2×、サポーターは最大 4× で、そのゲームでお使いの iPhone が実際に出せる速度だけが表示されます。Emura がプレイ中に測定しています。iPhone が熱いあいだ、早送りはオフになります。

コントローラやキーボードは使えますか？

はい。iPhone や iPad が対応しているコントローラなら、つなげばすぐに使えます。Xbox、PlayStation、Switch Pro コントローラーと Joy-Con、MFi コントローラ、スマホに取り付けるタイプのコントローラ、そしてキーボードも使えます。画面上のボタンは表示されなくなります。どのボタンが何をするかは「設定 › コントローラ」で確認でき、A と B の入れ替えもできます。ほかのボタンを変えるには、デバイスの「設定」アプリで「一般 › ゲームコントローラ」を開いてください。

スキンは使えますか？

はい、無料で使えます。「設定 › スキン」でスキンを読み込み、ゲーム機ごとに 1 つ選べます。3DS ゲームでは Emura 独自の操作ボタンを使います。

振動をオフにできますか？

振動するゲームの振動は「設定 › プレイ中」でオフにできます。画面上のボタンを押したときの軽い振動はオフにできません。

Emura ボタンを動かしたり隠したりできますか？

スキンを使えば、スキンの作者が決めた位置に置かれます。DS のレイアウトには、左利き・右利きの設定もあります。

マイクは使えますか？

はい、DS と 3DS のゲームで使えます。ゲーム機と同じように、iPhone や iPad に息を吹きかけたり話しかけたりしてください。Emura がマイクを使うのは、ゲームが音を聞いているときだけです。息を吹きかける操作では、大きな音なら何でも反応します。

モーション操作は使えますか？

はい、3DS のゲームで使えます。iPhone や iPad を傾けると、本体のモーションセンサーが動きを伝えます。モーションセンサーや光センサーを搭載したゲームボーイ・ゲームボーイアドバンスのカートリッジにも、近日対応予定です。

巻き戻しはできますか？

このバージョンではできません。

友だちと遊んだり、チートを使ったりできますか？

このバージョンではできません。ゲームは1台のデバイスで遊ぶもので、通信ケーブル、ワイヤレス通信、オンラインプレイ、チートには対応していません。

iPad のSplit View やステージマネージャで使えますか？

はい、どのウインドウサイズでも使えます。使っていないウインドウのゲームは一時停止し（「設定」で変更できます）、同時に遊べるゲームは1つです。テレビや外部ディスプレイでのプレイには、まだ対応していません。Apple Pencil はタッチスクリーン上で指と同じように使えます。

問題

うまくいかないときは

ゲームが起動しません。

Emura が理由を表示します。多くの場合、ゲームが暗号化されている（Emura は復号済みのゲームだけを遊べます）か、ファイルが壊れているか、そのゲーム機用のゲームではありません。3DS のゲームなら、.cia ではなく .3ds、.cci、.cxi のファイルか確認してください。以前は起動していたなら、「編集」で更新データや追加コンテンツを外すか、「前のセーブデータに戻す」を試してください。それでも起動しない場合は、報告を送ってください。

ゲームにパッケージ画像がありません。

Emura はパッケージ画像をインターネットから探します。接続を確認してから「設定 › アートワーク › すべてのアートワークを更新」をタップしてください。自分で選ぶこともできます。ゲームのページで「編集」をタップし、「写真」、「ファイル」、または SteamGridDB から画像を選んでください（SteamGridDB を使うには、ご自身の無料キーを「設定 › アートワーク」で入力します）。

音が出ません。

音量を確認してください。「設定 › 消音モードでも音を出す」がオン（初期設定）の場合、消音モードでもゲームの音が出ます。オフにすると、消音スイッチに従います。ほかのアプリで音楽を再生しているあいだは、ゲームの音は出ません。

ゲームがカメラなどのアクセス許可を求めてきます。

ゲームが初めて必要としたときに、Emura が許可を求めます。回答を変更するには、「設定 › アクセス許可」を開いてください。

ゲームの動作が遅い、または iPhone が熱くなります。

3D ゲームは iPhone に最も負荷をかけます。低電力モードでは動作が遅くなり、熱くなった iPhone は自ら速度を落とします。iPhone を冷まし、熱くなる場合はケースや充電器を外して遊んでください。それでも遅い場合は、どのゲームか、どの iPhone・iPad かをお知らせください。

DS のムービーシーンで黒い帯が出るのはなぜですか？

映画のレターボックスのように、ゲーム自体が描いているものです。上画面の上部と下画面の下部に帯が表示されます。本物の DS でも同じ帯が表示されるため、これはゲーム本来の見た目で、エミュレーションのエラーではありません。

うまく動かないゲームを報告するには？

問題が起きた直後に、ゲームメニューを開いて吹き出しのアイコン（問題を報告）をタップします。Emura が直前のプレイ、ゲームの動作のなめらかさ、画面をまとめるので、私たちも問題を自分の目で確認できます。AirDrop で共有するか、「メール」で emura.support@icloud.com に送ってください。

GitHub で報告することも、r/EmuraApp に Bug フレアを付けて投稿することもできます。ゲームファイルは絶対に添付しないでください。

どのゲームも本体とまったく同じように表示・動作しますか？

まだすべてではありません。現時点でわかっていること：3DS では霧の効果のひとつが描画されないため、一部のムービーなど、ぼかしのかかる場面がくっきり表示されます。DS では 3D モデルのなめらかな輪郭は本体に近いものの、少し違って見えることがあります。表示がおかしいときは報告してください。一つひとつの報告が修正につながります。

動作するゲームの一覧はありますか？

まだありません。うまく動かないゲームがあれば報告してください。一つひとつの報告が修正につながります。

Emura を削除すると、ゲームはどうなりますか？

アプリを削除すると、アプリ内のゲームとセーブデータも削除されます。これらは iPhone のバックアップ（iCloud バックアップまたはコンピュータ）に含まれているため、バックアップから復元すれば元に戻ります。

Emura をサポートしている場合は、セーブデータとステートセーブが iCloud アカウントにも保存されています。Emura を再インストールして同じゲームを読み込めば、元に戻ります。

Emura をサポート

サブスクリプション

Emura は無料ですか？

はい。すべてのゲーム機を無料で、広告なしで遊べます。サポーターは Emura の開発を支え、ステートセーブ、より速い早送り、使っているすべての iPhone と iPad で使える iCloud 上のセーブデータ、ゲーム機に iPhone と同じカラー、画面の光を利用できます。無料トライアルで先に試すこともできます。

サブスクリプションを復元・キャンセルするには？

新しい iPhone で復元するには、「設定 › Emura をサポート」を開いて「購入を復元」をタップします。キャンセルするには、iPhone の「設定 › ユーザ名 › サブスクリプション」を開いてください。

2台のデバイスで遊んでいます。どちらのセーブデータが残りますか？

両方で同じセーブデータを変更した場合は、新しいほうが残ります。もう一方のコピーは「設定 › iCloud › 保管中のコピー」に30日間保管され、そこから復元できます。

iCloud の容量がいっぱいです。

Emura がお知らせします。新しいセーブデータはデバイスに残り、空きができしだい同期されます。

サブスクリプションが終了するとどうなりますか？

すべてが無料の状態に戻り、何も削除されません。iCloud 同期は停止しますが、セーブデータは iPhone に残り、すでに iCloud にあるものもそのまま残ります。ステートセーブはロックされた状態で一覧に残ります。削除することはでき、再び Emura をサポートすれば、またロードできるようになります。

Emura は私の情報を収集しますか？

Emura が自ら収集することはありません。アカウントも、広告も、トラッキングもありません。問題の報告が iPhone の外に出るのは、あなた自身が共有したときだけです。詳しくはプライバシーポリシーをご覧ください。

答えが見つからない場合は、emura.support@icloud.com までご連絡いただくか、r/EmuraApp で質問してください。
