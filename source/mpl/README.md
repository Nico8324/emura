# TAMA5.swift

The source of Emura's Bandai TAMA5 cartridge support (Game Boy, used by one Japan-only Tamagotchi game), as shipped in the Emura app.

- **Origin:** a Swift translation of mGBA's `src/gb/mbc/tama5.c`, Copyright (c) 2013-2016 Jeffrey Pfau, with Emura's changes (the TAMA6 calendar is Emura's own).
